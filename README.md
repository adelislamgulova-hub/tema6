# ParkCity — сервис аренды парковочных мест (MVP)

Водитель находит свободное место на карте, бронирует на нужное время и платит онлайн. Владелец сдаёт место и получает выплаты. Сотрудники проверяют места, разбирают жалобы и следят за платежами.

Требования и диаграммы: [`docs/analytics`](docs/analytics). Что и где реализовано: [`docs/COVERAGE.md`](docs/COVERAGE.md).

## Состав

| Папка | Что внутри |
|-------|-----------|
| `backend/` | Flask API, бизнес-правила, фоновые задачи, тесты (`unittest`) |
| `frontend/index.html` | Клиент водителя и владельца (мобильный веб, вкладки «Карта / Мои брони / Профиль») |
| `frontend/admin.html` | Админ-панель, только для компьютера |
| `deploy/`, `docker-compose.yml` | nginx с HTTPS, API, воркер фоновых задач |

## Быстрый запуск

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

flask --app wsgi seed-demo                                  # 5 демо-мест в центре Москвы
flask --app wsgi create-admin --email admin@example.ru --password 'сложный-пароль'
flask --app wsgi run                                        # http://localhost:5000
flask --app wsgi jobs --loop                                # в другом терминале: фоновые задачи
```

`create-admin` печатает секрет 2FA - добавьте его в приложение-аутентификатор (Google Authenticator, Яндекс Ключ и т.п.), без кода в админку не войти.

- Приложение: http://localhost:5000
- Админ-панель: http://localhost:5000/admin.html
- В демо-режиме код входа показывается на экране и в логе сервера, оплата - кнопка «Оплатить» без реальных денег (`PARKCITY_PAYMENT_PROVIDER=mock`).

Карта: по умолчанию OpenStreetMap (Leaflet). Чтобы включить Яндекс Карты, впишите ключ в `frontend/config.js` (`YANDEX_MAPS_API_KEY`).

## Тесты

```bash
cd backend && python -m unittest discover -s tests -t . -v
```

29 тестов проверяют все десять бизнес-правил, матрицу прав, вход по коду, загрузку фото, удаление данных и выплаты.

## Прод

1. Скопируйте `.env.example` в `.env`, заполните, **поставьте `PARKCITY_DEV_EXPOSE_CODE=0`**.
2. Положите сертификаты в `deploy/certs/` (`fullchain.pem`, `privkey.pem`).
3. `docker compose up -d --build`
4. Резервная копия: cron `0 3 * * * python backend/scripts/backup.py /backups`.
5. В кабинете ЮKassa укажите webhook `https://<домен>/api/payments/webhook`.

## Что НЕ доделано и о чём надо знать

- **Мобильные приложения iOS/Android не сделаны.** Клиент - мобильная веб-версия; API готов для нативных клиентов (токен в `Authorization`, версия в `X-Client-Version`).
- **База данных - SQLite**, а не PostgreSQL из диаграммы развёртывания. Весь SQL простой, но переход потребует ORM или правки запросов, миграций пока нет. SQLite выдержит MVP на одном сервере, но не горизонтальное масштабирование и не 3 000 одновременных пользователей с запасом. Поиск мест сейчас фильтруется в Python, на росте нужен геоиндекс (PostGIS).
- **SMS, почта и push - заглушки** (пишут в лог и в ленту уведомлений в приложении). Нужно подключить шлюзы в `backend/app/notify.py`.
- **Интеграция с ЮKassa написана по документации, но не проверена** на реальном магазине. Нужны тестовые `shopId` и секрет. Чеки по 54-ФЗ пока формируются внутри системы как записи; фискализация через ЮKassa не подключена.
- **Яндекс Карты** не проверены (нужен ключ и сеть), проверен запасной вариант на Leaflet.
- Фото хранятся на диске сервера, а не в объектном хранилище.
- Юридические тексты (оферта, согласие на обработку ПДн) - заглушка в виде чекбокса; нужны настоящие документы от юриста.
- Не входят в MVP по решению заказчика: отзывы, промокоды, месячная аренда, шлагбаумы, несколько городов (но структура под города готова).
